// ============================================================ // 공개증거(전시대) 참여자 API // Google Sheets → Apps Script → GitHub Pages // // ★ 번호를 기준으로 데이터를 읽습니다. // // 1-1 ~ 1-17 = 참여자 // 2-1 ~ 2-2 = 타 회중 참여자 // 3-1 ~ 3-10 = 미 참여자 // 4-1 ~ = 참고 사항 // 5 = 기준일 // // B열 = A집단 // C열 = B집단 // D열 = C집단 // E열 = D집단 // ============================================================ // ============================================================ // 웹 API // ============================================================ function doGet() { try { const result = getExhibitionData(); return ContentService .createTextOutput( JSON.stringify(result) ) .setMimeType( ContentService.MimeType.JSON ); } catch (error) { console.error(error); return ContentService .createTextOutput( JSON.stringify({ success: false, error: String(error), message: "전시대 참여자 데이터를 불러오는 중 오류가 발생했습니다." }) ) .setMimeType( ContentService.MimeType.JSON ); } } // ============================================================ // 대상 시트 찾기 // // ★ 기존처럼 "참여자"라는 글자를 찾지 않습니다. // // A열에 // 1- // 2- // 3- // 4- // 5 // 번호가 있는 시트를 찾습니다. // ============================================================ function getTargetSheet() { const spreadsheet = SpreadsheetApp.getActiveSpreadsheet(); if (!spreadsheet) { throw new Error( "Google Spreadsheet를 찾을 수 없습니다." ); } const sheets = spreadsheet.getSheets(); for (let i = 0; i < sheets.length; i++) { const sheet = sheets[i]; const values = sheet .getDataRange() .getDisplayValues(); let has1 = false; let has2 = false; let has3 = false; for (let r = 0; r < values.length; r++) { const number = cleanText(values[r][0]); if (/^1-\d+$/.test(number)) { has1 = true; } if (/^2-\d+$/.test(number)) { has2 = true; } if (/^3-\d+$/.test(number)) { has3 = true; } } if (has1 && has2 && has3) { return sheet; } } throw new Error( "1- / 2- / 3- 번호가 있는 전시대 참여자 시트를 찾지 못했습니다." ); } // ============================================================ // 전시대 데이터 읽기 // ============================================================ function getExhibitionData() { const sheet = getTargetSheet(); const values = sheet .getDataRange() .getDisplayValues(); // ========================================================== // 결과 // ========================================================== const result = { success: true, participants: [], otherParticipants: [], nonParticipants: [], references: [], referenceDate: "", counts: { participants: 0, otherParticipants: 0, nonParticipants: 0, references: 0, participantGroups: { "A집단": 0, "B집단": 0, "C집단": 0, "D집단": 0 }, nonParticipantGroups: { "A집단": 0, "B집단": 0, "C집단": 0, "D집단": 0 } } }; // ========================================================== // 집단 // // B열 = A집단 // C열 = B집단 // D열 = C집단 // E열 = D집단 // ========================================================== const groupNames = { 1: "A집단", 2: "B집단", 3: "C집단", 4: "D집단" }; // ========================================================== // 전체 행 검사 // ========================================================== for ( let row = 0; row < values.length; row++ ) { const rowValues = values[row]; if (!rowValues || rowValues.length === 0) { continue; } // -------------------------------------------------------- // A열 번호 // -------------------------------------------------------- const number = cleanText( rowValues[0] ); // ======================================================== // 1번 영역 // // 1-1 // 1-2 // 1-3 // ... // // 참여자 // ======================================================== if ( /^1-\d+$/.test(number) ) { readGroupNames( rowValues, result.participants, groupNames ); continue; } // ======================================================== // 2번 영역 // // 2-1 // 2-2 // ... // // 타 회중 참여자 // ======================================================== if ( /^2-\d+$/.test(number) ) { readOtherParticipants( rowValues, result.otherParticipants ); continue; } // ======================================================== // 3번 영역 // // 3-1 // 3-2 // ... // // 미 참여자 // ======================================================== if ( /^3-\d+$/.test(number) ) { readGroupNames( rowValues, result.nonParticipants, groupNames ); continue; } // ======================================================== // 4번 영역 // // 4-1 // 4-2 // ... // // 참고 사항 // ======================================================== if ( /^4-\d+$/.test(number) ) { for ( let col = 1; col <= 4; col++ ) { const text = cleanText( rowValues[col] ); if (!text) { continue; } result.references.push( text ); } continue; } // ======================================================== // 5번 // // 기준일 // ======================================================== if ( number === "5" ) { for ( let col = 1; col < rowValues.length; col++ ) { const text = cleanText( rowValues[col] ); if (text) { result.referenceDate = text; break; } } continue; } } // ========================================================== // 중복 제거 // ========================================================== result.participants = removeDuplicates( result.participants, function(item) { return ( item.name + "|" + item.group ); } ); result.otherParticipants = removeDuplicates( result.otherParticipants, function(item) { return item.name; } ); result.nonParticipants = removeDuplicates( result.nonParticipants, function(item) { return ( item.name + "|" + item.group ); } ); result.references = Array.from( new Set( result.references ) ); // ========================================================== // 전체 인원수 // ========================================================== result.counts.participants = result.participants.length; result.counts.otherParticipants = result.otherParticipants.length; result.counts.nonParticipants = result.nonParticipants.length; result.counts.references = result.references.length; // ========================================================== // 참여자 집단별 인원수 // ========================================================== result.participants.forEach( function(person) { if ( result.counts .participantGroups .hasOwnProperty( person.group ) ) { result.counts .participantGroups[ person.group ]++; } } ); // ========================================================== // 미 참여자 집단별 인원수 // ========================================================== result.nonParticipants.forEach( function(person) { if ( result.counts .nonParticipantGroups .hasOwnProperty( person.group ) ) { result.counts .nonParticipantGroups[ person.group ]++; } } ); return result; } // ============================================================ // 참여자 / 미 참여자 읽기 // // B = A집단 // C = B집단 // D = C집단 // E = D집단 // ============================================================ function readGroupNames( rowValues, targetArray, groupNames ) { for ( let col = 1; col <= 4; col++ ) { const name = cleanText( rowValues[col] ); if ( !isValidName(name) ) { continue; } targetArray.push({ name: name, group: groupNames[col] }); } } // ============================================================ // 타 회중 참여자 읽기 // // B~E열을 모두 읽습니다. // ============================================================ function readOtherParticipants( rowValues, targetArray ) { for ( let col = 1; col <= 4; col++ ) { const name = cleanText( rowValues[col] ); if ( !isValidName(name) ) { continue; } targetArray.push({ name: name }); } } // ============================================================ // 텍스트 정리 // ============================================================ function cleanText(value) { return String( value || "" ) .replace(/\*/g, "") .replace(/\s+/g, " ") .trim(); } // ============================================================ // 이름 유효성 검사 // ============================================================ function isValidName(name) { if (!name) { return false; } const invalidTexts = [ "A집단", "B집단", "C집단", "D집단", "참여자", "타 회중 참여자", "미 참여자", "참고", "참고 사항", "참고사항", "참조", "기준일", "공개증거(전시대) 참여자 명단" ]; if ( invalidTexts.includes(name) ) { return false; } // 번호 자체 제외 if ( /^\d+(?:-\d+)?$/.test(name) ) { return false; } // 날짜 제외 if ( /^\d{4}[.\-/]\d{1,2}[.\-/]\d{1,2}/ .test(name) ) { return false; } return true; } // ============================================================ // 중복 제거 // ============================================================ function removeDuplicates( array, keyFunction ) { const map = new Map(); array.forEach( function(item) { const key = keyFunction(item); if ( !map.has(key) ) { map.set( key, item ); } } ); return Array.from( map.values() ); } // ============================================================ // 테스트 // // Apps Script에서 testAPI 실행 // ============================================================ function testAPI() { const result = getExhibitionData(); console.log( JSON.stringify( result, null, 2 ) ); return result; }
